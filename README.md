# 信札 · 每周情绪回信

把一周的对话写成一封回信的前端页面。纯静态 HTML / CSS / JS，不需要构建。

```bash
npm run preview   # http://localhost:4173
```

## 结构

| 区域 | 内容 |
|---|---|
| 顶栏 | 品牌 · 定位（第几封 / 读信·回顾 / 第几段）· 导航，与下方三栏对齐；底边细线是阅读进度 |
| 左栏 160px「往期」 | 往期信件列表，点选切换整封信与右栏数据 |
| 中栏 640px「信件」 | 信头（第十二封 · 9月21—27日 · 写给阿禾）→ 九段回信 → 信末（承接上周心愿）→ 附问与回复框 |
| 右栏 224px「回顾」 | 七日话题 · 情绪折线 · 三个关键词 |
| 页脚 | 字号 / 纸色（米白·素绢·夜读）/ 行距，记在本地 |

桌面端总宽 1120px 居中，栏距 48px，左右栏随滚动常驻；≤880px 时改为单列，顺序为信件 → 回顾 → 档案。

## 交互

- 悬停或聚焦某一天（话题行或折线点）：折线显示十字线和提示，信中对应段落用左侧边线标出，其余段落淡出；点击会滚动到该段落
- 点选关键词：在正文和信末用记号笔标出，再点一次或按 Esc 取消
- 回复框：自动保存草稿，有字数统计，⌘/Ctrl + Enter 寄出；寄出后显示为封好的信，可以「拆开重写」
- 定位：桌面端随阅读显示「第几段 · 共几段」；手机端导航按滚动位置高亮

信件内容是虚构的示例数据，在 `js/data.js` 里。截图见 `docs/screenshots/`。
